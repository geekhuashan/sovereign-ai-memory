# Changelog

## 0.1.0

First standalone public core, extracted from a private local memory workflow without its deployment history or personal configuration.

- Codex, Claude Code and Grok CLI visible-message adapters.
- SQLite FTS5 search, stable provenance and bounded Markdown context packs.
- User-local runtime paths and an installable `sam` command.
- Opt-in raw copying, restrictive context-file creation and synthetic demonstrations.
- Python standard-library tests and Linux/macOS CI.

This is an alpha release. Vendor session formats may change, search is lexical, and output masking is best-effort.
